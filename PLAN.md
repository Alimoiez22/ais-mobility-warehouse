## 1. Goal and definition of done
A reproducible warehouse on real ship-tracking data that shows data-quality work, dimensional modelling and measured query performance.

Done means: from a clean clone, `docker compose up` + `make all` reproduces every number in the README; tests pass; every figure is regenerated by a script.

## 2. Research questions
- RQ1: What data-quality problems exist in raw AIS and how many rows does each cleaning rule remove?
- RQ2: Can a multidimensional model (MultiDim, Vaisman & Zimanyi) answer realistic maritime questions with OLAP queries?
- RQ3: How much do none vs GiST vs SP-GiST indexes change latency? (5 runs, median, IQR, EXPLAIN plans.)

Out of scope: streaming, ML, cloud.

## 4. Stack

CPU architecture: x86-64 (confirmed), image runs. Smoke test passed on 28 Oct 2026: PostGIS 3.6.4 and MobilityDB 1.3.0 load in the `latest` image (psql client is PostgreSQL 18). `latest` is NOT reproducible: on D2 pin an exact tag on Docker Hub and record the digest tested (sha256:8409e3897e2b88561bef4374110c3da5f7ff56838a7745315f1c2f111305dd24).
